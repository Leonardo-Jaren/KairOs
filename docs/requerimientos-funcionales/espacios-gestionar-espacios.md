# RF-ESP-001: Gestionar espacios

## Descripción

El sistema debe permitir consultar, crear, editar y desactivar espacios físicos
como laboratorios, aulas, oficinas y salas de cómputo.

## Criterios funcionales

- Administradores pueden crear, editar y desactivar espacios.
- Técnicos pueden consultar el listado y el detalle en modo de solo lectura.
- El código del espacio es único y se normaliza en mayúsculas.
- El listado permite filtrar por texto, tipo y estado.
- Cada espacio muestra responsable, ubicación y cantidad de equipos.
- El detalle presenta los equipos vigentes asignados al espacio.
- La eliminación es lógica para conservar trazabilidad y relaciones históricas.
