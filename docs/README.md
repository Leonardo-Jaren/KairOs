# Documentacion KairOs

Documentacion funcional y de proceso del proyecto.

## Estructura

| Carpeta | Proposito |
|---------|-----------|
| `requerimientos-funcionales/` | Requerimientos funcionales (RF) por modulo |
| `requerimientos-no-funcionales/` | Requerimientos no funcionales (RNF) |
| `historias-de-usuario/` | Historias de usuario (HU) |
| `plantillas/` | Plantillas Markdown para crear nuevos documentos |

## Convencion de nombres

```
docs/<carpeta>/<modulo>-<slug>.md
```

Ejemplo: `docs/historias-de-usuario/equipos-listar-equipos.md`

## Reglas para IA y desarrolladores

Ver `CONTRIBUCION-IA.md` para arquitectura backend, convenciones de codigo, ramas, PRs y cuándo generar documentacion.
