# HU-ESP-001: Administrar espacios físicos

Como administrador de KairOs, quiero registrar y mantener los espacios físicos
de la institución para conocer su ubicación, responsables y equipos asignados.

## Criterios de aceptación

1. Puedo listar espacios con búsqueda, filtros e indicadores.
2. Puedo registrar código, tipo, pabellón, piso y estado.
3. No puedo duplicar un código existente.
4. Puedo editar los datos de un espacio.
5. Puedo desactivar un espacio conservando su historial.
6. Puedo abrir el detalle y visualizar sus equipos asignados.
7. Un técnico puede consultar, pero no modificar.
8. Un usuario sin rol administrativo no puede acceder.
